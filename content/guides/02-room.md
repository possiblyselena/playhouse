# Creating Your Room

Your box must be **14 cm x 14 cm x 14 cm** and have the dimensions and design for the bottom plate so it connects properly.

## Bottom and Top Plate

What we need to do to create a plate with a border gap for the walls to go. You can do this however way you like, but this is the scrappy way I did it.

1. Create a sketch and draw a square. Set the dimensions to 14cm by 14cm.

![Bottom plate sketch](/guide/assets/image.png)

2. Extrude the square by 0.25cm

![Extruded plate](/guide/assets/image-1.png)

3. Create a sketch, select the top of the base as the plane. Draw a rectangle on one side of the square, starting from the corner to the top. Set the width of the rectangle as 0.25cm as follows. Repeat for the other side of the square. Draw an additional line at the top and set it 0.25cm from the edge.

![Wall groove sketch](/guide/assets/image-2.png)

5. Now extrude cut that sketch by 0.15cm.

![Groove cut](/guide/assets/image-3.png)

## Side Plate

1. Create a new part studio, create a sketch and draw a square. Set the dimensions to 13.75cm by 13.75cm.

![Side plate sketch](/guide/assets/image-4.png)

2. Extrude the square by 0.25cm.

## Back Plate

1. Create and new part studio, create a sketch and draw a square. Set the dimensions to 14cm by 13.75cm.

![Back plate sketch](/guide/assets/image-5.png)

2. Extrude the square by 0.25cm
