# Creating Your Room

Your box must be **14 cm x 14 cm x 14 cm** and have the dimensions and design for the bottom plate so it connects properly.

**Bottom and Top Plate**

What we need to do to create a plate with a border gap for the walls to go. You can do this however way you like, but this is the scrappy way I did it.

1. Create a sketch and draw a square. Set the dimensions to 14cm by 14cm.

2. Extrude the square by 0.25cm

3. Create a sketch, select the top of the base as the plane. Draw a rectangle on one side of the square, starting from the corner to the top. Set the width of the rectangle as 0.25cm as follows. Repeat for the other side of the square.

4. Draw an additional line at the top and set it 0.25cm from the edge.

5. Now extrude cut that sketch by like 0.10 cm

**Side Plate**

1. Create a sketch and draw a square. Set the dimensions to 14cm by 13.75cm.

2. Extrude the square by 0.25cm.

**Back Plate**

1. Create a sketch and draw a square. Set the dimensions to 14cm by 14cm.

You're probably asking, why can't I just make a box? It's take less space for shipping and if you want to add things like windows or designs to your walls, it's much easier to print.
